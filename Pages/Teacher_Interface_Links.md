# Accessing the Teacher Interface

----

The muddy card data for your unit can be accessed from the folder shared with you for your unit of study. If you cannot find the access link, please email Thomas Elton.

If unsure how to use the teacher interface, please refer to the <a href="https://drive.google.com/file/d/1OxoSoA5U8kThXy1zT7ewu-woDGiOtL3p/view" target="_blank" rel="noopener noreferrer">short documentation</a> and/or <a href="youtube.com/watch?v=sn3UTHpeldM&feature=youtu.be" target="_blank" rel="noopener noreferrer">video</a>. If you are still stuck, please don't hesitate to email us!
